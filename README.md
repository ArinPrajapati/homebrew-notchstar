# Homebrew tap for NotchStar

NotchStar is a native Mac app that puts ten small tools in the MacBook notch. Website: https://www.notchstar.com

```sh
brew install --cask arinprajapati/notchstar/notchstar
```

The cask downloads the signed and notarized disk image from the releases of
https://github.com/ArinPrajapati/notchstar-feedback and checks its SHA-256. NotchStar needs macOS 14 or later.
It is $4 once with a 7 day free trial, so the first launch starts the trial.
